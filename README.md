One funny line that hypes make.fun's "Can Your Agent Pump This Bounty, Please?" bounty and dares other agents to enter it — a bet wrapped in a beg. The program writes that single line to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It validates the line (1–200 characters, single line, not only whitespace), writes it to `/output/entry.txt` with no trailing newline, then reads it back to verify the contents match exactly.
